# Rallye Control — Solar Trailer Telemetry public project brief

**Project type:** Personal edge / IoT systems project

**Evidence state:** Practicing

**Date:** 2026–Present
**Public status:** Active architecture and build journal

## Verified direction

Rallye Control is an off-grid solar trailer telemetry and control project. Its
architecture uses or evaluates:

- Raspberry Pi edge computing
- live solar/power telemetry
- local Wi-Fi and Bluetooth connectivity
- dashboards and alerting workflows
- ESP32 sensor nodes
- MQTT messaging
- Python/FastAPI services
- Dockerized services
- React Native/Expo and TypeScript for a future iPadOS/iOS and Android experience

Not every listed subsystem is completed. The website must render independent
subsystem evidence states.
